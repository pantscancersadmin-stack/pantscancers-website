# Pants Cancers Website

Static HTML, CSS, and JavaScript website for **Pants Cancers** ([pantscancer.co.uk](https://pantscancer.co.uk/)), Registered UK Charity No. 1147098 — raising awareness of cancers affecting the pants area and funding the CancerRehab Centre in Falmouth, Cornwall.

Built & maintained by **Simply Computerz** ([simplycomputerz.co.uk](https://simplycomputerz.co.uk)).

## Hosting & Deployment

- **Netlify + GitHub:** Continuous deployment via `netlify.toml` and `_redirects` (no build command; publish directory `.`).
- **Bluehost (Apache):** Supported directly using `.htaccess`. See [BLUEHOST_DEPLOYMENT_GUIDE.md](BLUEHOST_DEPLOYMENT_GUIDE.md) for upload steps.
